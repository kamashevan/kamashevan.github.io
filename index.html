01 — THE IDEA

Read the interface before you build it.

An INMARIUM class list is a sentence: first say what the thing is, then how it behaves, then how it should feel.

01

Name the structure

Start with a visual primitive: grid, flex, stack, cluster, container.

02

Describe the relationship

Add cols-3, gap-6, items-center, justify-between.

03

Give it character

Finish with p-6, rounded-xl, shadow-lg, or semantic color.

02 — FIRST SENTENCE

Build a card without “thinking in CSS”.

Designer reads: “A card, vertical, with medium space, generous padding, rounded corners and a soft shadow.”

03 — COMPOSITION

Four words cover most layout thinking.

Choose the relationship that matches the composition you see.

Grid

Rows and columns.

grid cols-3 gap-4

Stack

Vertical rhythm.

stack gap-3

Cluster

Natural wrapping groups.

cluster gap-3

Flex

Precise one-dimensional alignment.

flex row justify-between
04 — SPACING

Space is part of the sentence.

The same scale drives gaps, margins and padding, so compositions keep a shared rhythm.

gap-2   gap-4   gap-8
p-4     px-6    py-8
mt-6    mb-12   mx-auto
Think visually: gap is the space between children; padding is the breathing room inside; margin moves the object relative to its surroundings.

05 — COMPONENTS

Start with meaning. Modify with plain words.

Components establish the role. Modifiers describe emphasis, size and treatment.

Buttons

btn primary lg rounded-full

Messages

alert success / warning / danger / info
Success — the action is complete.
Warning — check this before continuing.
Danger — something needs attention.

Badges

06 — RESPONSIVE

Say what changes, where it changes.

Desktop can be four columns. Tablet can be two. Mobile can be one. The markup says exactly that.

<div class="grid cols-4 tablet-cols-2 mobile-cols-1 gap-6">
  ...
</div>
