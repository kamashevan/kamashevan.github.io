Beginner TutorialFramework 1.0

Learn to speak INMARIUM.

This book teaches INMARIUM as a visual language, not as a list of CSS tricks. Every chapter explains what a component means, how to read its classes, what it looks like, and how to combine it with other words.

Begin lesson 1Back to overviewAll classes
If you are a designer: read class names as visual instructions. If you are a developer: read them as explicit structure and state. Both lead to the same interface.
01 — FOUNDATIONS

Everything begins with shared visual rules.

INMARIUM keeps colors, spacing, radius, shadows, borders, typography and motion consistent. You normally use these rules through simple classes rather than editing raw values every time.

Think in tokens, not random values

A spacing word such as gap-4 belongs to the same scale as p-4 and mt-4. A radius word such as rounded-xl is consistent everywhere.

Read it: “Use the framework's level-4 space”, not “invent another 17px gap”.

02 — LAYOUT LANGUAGE

Choose the relationship between things.

Most interfaces can be described with four primitives: Grid, Stack, Cluster and Flex.

Grid

Use when items belong to rows and columns.

123
grid cols-3 gap-3

Stack

Use for vertical rhythm: headings, paragraphs, fields, cards.

ABC
stack gap-2

Cluster

Use for groups that may naturally wrap.

DesignCodeCreatePublish
cluster gap-2

Flex

Use when you need precise one-dimensional alignment.

Logo
flex row justify-between items-center

Alignment vocabulary

WordMeaning
items-centerCenter children across the cross axis.
justify-betweenPut free space between children.
place-centerCenter both directions in a grid-like context.
self-endMove one child to the end.

A full sentence

<div class="grid cols-3 gap-6 items-stretch">
  ...
</div>

03 — UTILITIES

Utilities are the adjectives of the language.

A component says what something is. Utilities describe local details: size, space, alignment, surface, position and visibility.

FamilyExamplesUse it for
Spacingp-6 gap-4 mt-8 mx-autoBreathing room and rhythm
Sizingw-full fit h-screen max-w-lgWidth and height
Radiusrounded-md rounded-xl rounded-fullCorner character

Important: utilities come after components in Framework 1.0's cascade. That means a local utility is the final small instruction. Example: card rounded-3xl shadow-xl keeps the card behavior but changes its radius and elevation.
04 — BUTTONS

Button = role + meaning + treatment + size.

The base word is btn. Add a semantic color, a visual variant and optionally a size.

Read: btn primary lg rounded-full → “A button, primary action, large, fully rounded.”
<button class="btn primary">Save</button>
<button class="btn secondary outline">Cancel</button>
<button class="btn success soft">Completed</button>
<button class="btn danger ghost">Delete</button>
<a class="btn primary link" href="#">Learn more</a>
Learn more

Sizes

Use size modifiers only when the button's emphasis or touch target truly needs to change.

Designer note: color communicates meaning; variant communicates emphasis. A primary solid button is stronger than a primary outline or ghost button.
05 — FORMS

Forms are built from readable field sentences.

A field is a vertical relationship: label → control → hint or error.

    <input class="input" id="email" type="email">
    <span class="hint">We will never share it.</span>
  </div>
</form>

20J — MODERN TYPE

Control wrapping without hand-written CSS.

A balanced heading keeps short headline lines visually even.

Use text-balance mostly for headings.

Clamping limits long summaries to a predictable number of lines. This is especially useful in cards, grids and search results where content length varies from item to item.

<h1 class="text-balance">...</h1>
<p class="text-pretty clamp-3">...</p>

22 — THEMES

Semantic language lets the same interface change character.

Framework 1.0 includes default, dark, pastel and corporate themes. Components keep their meaning because they use semantic variables.

<html data-theme="dark">
  ...
</html>
If you force an exact utility such as bg-white, you intentionally override theme behavior. Use bg-surface when you want the surface to adapt automatically.
23 — COMPLETE PATTERNS

Now speak in complete interface sentences.

The goal is not to memorize components independently. The goal is to combine them into understandable compositions.

Pattern C — The INMARIUM decision order

  1. Name the structure. Grid, stack, cluster, flex, container, component.
  2. Describe relationships. Columns, direction, alignment, wrapping.
  3. Add rhythm. Gap, padding, margin.
  4. Add visual character. Radius, shadow, border, semantic color.
  5. Describe change. Tablet and mobile behavior.
  6. Add JavaScript only for state. Open, active, selected, expanded.
